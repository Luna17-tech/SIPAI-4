## 📖 Tentang Proyek

**SIPAI-4 (Sistem Informasi Pembelajaran Pendidikan Agama Islam Terintegrasi Kelas IV)** merupakan aplikasi pembelajaran berbasis web yang dikembangkan untuk membantu proses pembelajaran Pendidikan Agama Islam (PAI) bagi siswa kelas IV sekolah dasar.

Aplikasi ini dikembangkan sebagai proyek tugas akhir dengan studi kasus pada **SD Aisyiyah Multilingual Darussalam Kudus**.

SIPAI-4 dirancang untuk mengintegrasikan seluruh materi pembelajaran PAI kelas IV ke dalam satu platform digital yang dilengkapi dengan fitur latihan soal, penyimpanan hasil evaluasi, serta elemen gamifikasi untuk meningkatkan keterlibatan siswa dalam belajar.

## 🎯 Tujuan Pengembangan

- Menyediakan media pembelajaran PAI berbasis digital.
- Mengintegrasikan materi PAI kelas IV dalam satu aplikasi.
- Mempermudah siswa dalam mengakses materi pembelajaran.
- Mendukung proses evaluasi melalui latihan soal.
- Meningkatkan motivasi belajar melalui penerapan gamifikasi.

## ✨ Fitur Aplikasi

1. **Login Pengguna**  
   Menyediakan autentikasi untuk pengguna aplikasi.

2. **Manajemen Materi Pembelajaran**  
   Memungkinkan pengelolaan dan penyajian materi PAI kelas IV.

3. **Akses Materi Pembelajaran**  
   Memudahkan siswa mempelajari materi melalui aplikasi.

4. **Latihan Soal dan Kuis**  
   Menyediakan latihan soal untuk mengukur pemahaman siswa.

5. **Penyimpanan Hasil Evaluasi**  
   Menyimpan hasil pengerjaan dan nilai siswa menggunakan Firebase Realtime Database.

## ⚙️ Metode Pengembangan

Pengembangan aplikasi menggunakan metode **Research and Development (R&D)** dengan model pengembangan sistem **Waterfall**, yang meliputi tahapan:

1. **Analisis Kebutuhan** – Mengidentifikasi kebutuhan pengguna dan sistem pembelajaran.
2. **Perancangan Sistem** – Merancang alur sistem, antarmuka, dan kebutuhan database.
3. **Implementasi** – Membangun aplikasi berdasarkan rancangan yang telah dibuat.
4. **Pengujian** – Menguji fungsi aplikasi untuk memastikan fitur berjalan sesuai kebutuhan.
